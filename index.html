Tentang data & definisi metrik ＋

Sumber tunggal: tab “DATA PENJUALAN WUZZ VIA PARKEE” dalam List Pendaftaran Wuzz.xlsx terlampir. Snapshot 13 Oktober 2026; belum terhubung otomatis ke spreadsheet.

  • Catatan pendaftaran = baris dengan nama terisi, bukan pelanggan unik atau pesanan unik. Data dari tab lainnya tidak disertakan.
  • Tren bulanan memakai tanggal pendaftaran. Tanggal tidak terbaca tetap masuk total tanpa filter tanggal, tetapi tidak masuk grafik. Filter tanggal mengecualikannya.
  • Tanggal setelah 13 Oktober 2026 dipertahankan dan ditandai untuk diperiksa. Tidak ada pengubahan tanggal berdasarkan asumsi.
  • Dikirim menunjukkan status pengiriman pada sumber, bukan konfirmasi barang diterima. Motor, Motorcycle, dan Bike disatukan sebagai Motor.
  • Daerah berasal dari kolom City. Nilai kosong ditandai Belum diisi; nama daerah mengikuti sumber, tanpa geocoding atau estimasi dari alamat. Jumlah daerah tidak termasuk Belum diisi.
  • Filter berlaku untuk seluruh metrik, grafik, tabel, dan ekspor CSV. Klik batang bulan, kategori kendaraan, atau daerah untuk menerapkan filter; gunakan Reset filter untuk kembali.
  • File HTML ini memuat nama pelanggan. File tidak menyertakan nomor telepon, rekening, alamat lengkap, nominal, atau pembayaran.
